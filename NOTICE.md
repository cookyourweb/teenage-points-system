# Aviso — proyecto de uso personal

Este repositorio es el código de una aplicación familiar de puntos, tareas y acuerdos
para adolescentes, publicada **como portfolio técnico**, no como producto.

## Método pedagógico: no comercializable

La aplicación aplica un **método pedagógico aprendido en formación** — el **Método
Efera** (Error · Foco · Estrategia · Rol · Acción) y la tipología de tipos de
adolescente por colores — cuya **autoría es de Vicent Ginés Romero**. La autora de este
código fue alumna de su formación y lo utiliza **exclusivamente para uso personal con
su familia**.

**Este proyecto no se comercializa**: no se vende, no se licencia, no se ofrece como
servicio a terceros y no incluye contenido de sus libros.

El **contenido del método no está en este repositorio**: vive en una base de datos
privada y la aplicación lo lee en tiempo de ejecución. El repositorio contiene
únicamente código, y está estructurado para no depender de ese contenido.
