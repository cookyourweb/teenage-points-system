# Colores

Seis familias con nombre semantico. **El nombre dice para que sirve el color, no
que color es.** Por eso se llama `danger` y no `red`: el dia que la marca decida
que borrar se pinta en naranja, se cambia en un sitio y no hay que renombrar nada.

Cada familia tiene la escala completa de 50 a 950 y funciona con cualquier
utilidad de Tailwind: `bg-`, `text-`, `border-`, `ring-`, `from-`, `to-`.

## Como se usa

```jsx
<button className="bg-primary-600 text-white hover:bg-primary-700">
  Guardar
</button>

<div className="border border-neutral-200 bg-white text-neutral-900">
  <span className="text-neutral-500">Puntos</span>
</div>

<span className="text-success-600">Tarea completada</span>
```

## Que tono elegir

| Tono | Para que |
| --- | --- |
| **50 a 100** | Fondos suaves, avisos, estados seleccionados |
| **200 a 300** | Bordes y separadores |
| **400 a 500** | Iconos y texto secundario sobre fondo claro |
| **600 a 700** | **Fondos de boton y texto de color.** Es el rango de trabajo |
| **800 a 950** | Texto principal, fondos oscuros |

**Regla de contraste:** para texto sobre blanco, a partir de **600**. Los tonos
400 y 500 no llegan a los 4,5:1 que pide WCAG AA en texto normal.

## Los nombres crudos de Tailwind no existen

`bg-blue-500` y `bg-gray-100` no generan ninguna clase. La configuracion
**reemplaza** `theme.colors` en lugar de extenderlo, asi que la paleta por
defecto de Tailwind no esta disponible.

No es una convencion que haya que recordar: **no se puede incumplir.**

```jsx
<div className="bg-blue-500" />     {/* no pinta nada */}
<div className="bg-primary-500" />  {/* correcto */}
```

Si necesitas un color que no esta aqui, la respuesta no es escribir el nombre
crudo: es anadirlo a la paleta con un nombre que diga para que sirve.
